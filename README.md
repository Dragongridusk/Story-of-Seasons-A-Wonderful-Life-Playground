## **What is Story of Seasons: A Wonderful Life Playground?**


Designed as a **companion** for fans of *Story of Seasons*, this project enriches the original experience without altering core gameplay. It offers a seamless **enhancement** layer that respects the spirit of the game while giving you finer control over daily life on your farm.

---

## **Highlights & Enhancements**

| 🌱 Feature | 🎮 What it does |
|-----------|-----------------|
| **Dynamic Crop Planner** | Suggests optimal planting schedules based on weather forecasts. |
| **Friendship Optimizer** | Highlights NPCs with the highest interaction potential each week. |
| **Seasonal UI Tweaks** | Adjustable overlays for rainfall, temperature, and festivals. |
| **Harvest Logger** | Keeps a tidy record of yields, profits, and rare finds. |
| **Custom Hotkeys** | Map your favorite actions to convenient key combos. |
| **Performance Friendly** | Light‑weight **utility** that runs alongside the game without lag. |
